Mulai dari sekarang

Dari spreadsheet kosong menjadi dashboard pribadi.

Halaman ini mempertahankan semangat panduan asli: cukup beberapa langkah, lalu aplikasi siap dipakai.

1

Siapkan Google Sheets

Buka spreadsheet baru, lalu masuk ke Ekstensi → Apps Script.

2

Pasang script Yaumi

Gunakan project dan file script Yaumi yang sudah Anda miliki, lalu sesuaikan data profil serta target amalan.

3

Deploy sebagai Web App

Deploy Apps Script sebagai aplikasi web, lalu buka URL Yaumi dari HP atau desktop.

Catatan pemasangan

Detail menu, deployment, dan konfigurasi dapat mengikuti setup Apps Script Anda saat ini. Landing page ini sengaja tidak mempublikasikan kredensial, Script ID, atau data pribadi agar tetap aman.

Gunakan project Anda sendiri untuk lingkungan produksi. Demo di atas hanya menampilkan URL web app yang disediakan pada materi contoh landing page.
FAQ

Pertanyaan yang paling sering muncul.

Jawaban singkat agar Anda bisa memutuskan dengan tenang sebelum mulai.

Yaumi adalah dashboard mutaba'ah harian untuk mencatat capaian amalan, mengelola target, melihat riwayat, dan mengevaluasi progres melalui visualisasi data.

Ya. Modul Target memungkinkan Anda menambahkan nama amalan, target, satuan, serta mengatur urutannya sesuai kebutuhan pribadi.

Nilai di atas target tetap bisa dipertahankan sebagai data capaian. Dalam visualisasi progres yang baru, skala sumbu grafik menyesuaikan nilai tertinggi sehingga capaian seperti 150% atau 200% tetap terbaca.

Yaumi dirancang untuk ritme harian, tetapi fokus utamanya adalah membangun kebiasaan evaluasi yang realistis. Yang penting bukan sempurna setiap hari, melainkan kembali melanjutkan ketika terlewat.

Pada versi aplikasi yang sekarang, pesan motivasi ditentukan dari aturan capaian dan rata-rata progres. Jadi istilah “Smart Motivator” dipakai untuk menjelaskan umpan balik otomatis berbasis data, bukan klaim bahwa aplikasi memanggil model AI eksternal.
Satu langkah kecil hari ini

Mulai catat. Mulai melihat polanya. Mulai bertumbuh.

Yaumi bukan tentang mengejar angka sempurna. Yaumi adalah alat bantu untuk membuat evaluasi lebih terlihat, lebih ringan, dan lebih mudah dilanjutkan.
